网页视频港
WebVideoHarbor

一个完全免费、开源、本地运行的网页媒体技术项目，用于学习网页媒体识别、非加密 HLS 分片处理，以及浏览器与本地程序之间的通信。

查看安装使用说明 浏览 GitHub 仓库↗

处理位置

你的 Mac

媒体识别和文件处理在本机完成。扩展与本地助手不上传视频或下载记录。
