# WebVideoHarbor（网页视频港）：macOS 安装与使用说明

本工具包含 Chrome 扩展和运行在本机的下载助手。扩展只负责发现当前网页公开给浏览器的媒体候选；助手通过本机回环地址处理下载。它不是万能下载器，也不会尝试绕过网站保护。

## 一、准备环境

需要：

- macOS 与最新版 Google Chrome。
- Homebrew。
- Go，仅在构建本地助手时需要。
- FFmpeg，下载 M3U8/HLS 或合并平台音视频时需要；普通 MP4 不依赖它。

正式 macOS 安装包已包含固定版本的 `yt-dlp 2026.07.04` 平台解析器，不需要另外安装，也不会静默更新。直接从源码运行构建脚本只生成助手；需要平台下载时，请使用完整安装包。

在“终端”中进入本项目根目录，然后安装 Go 和 FFmpeg：

```zsh
brew install go ffmpeg
```

如果已经安装，Homebrew 会提示当前状态，不需要重复处理。

## 二、构建并启动本地助手

构建脚本使用当前 Homebrew Go，分别生成 Apple Silicon（arm64）与 Intel（x86_64）版本，再合成为 universal 可执行文件：

```zsh
./scripts/build-macos.zsh
```

构建产物位于 `work/dist/web-video-harbor-helper`。Go 只在这一步使用；运行助手本身不需要 Go。

启动助手：

```zsh
./scripts/start-helper.zsh
```

脚本会在后台启动助手，等待 `http://127.0.0.1:17432/health` 变为健康后才报告成功，并拒绝重复启动。状态目录固定为 `~/Library/Application Support/WebVideoHarbor/`，其中配置、PID 和日志仅供当前用户访问。

随时可以查看状态；输出只包含健康情况、FFmpeg、版本和目录，不显示配对密钥：

```zsh
./scripts/helper-status.zsh
```

## 三、获取配对密钥

首次运行会创建随机配对密钥。用下面的命令显示它：

```zsh
./work/dist/web-video-harbor-helper --print-token
```

终端中出现的一整行字符就是配对密钥。不要分享、截图、粘贴到聊天或提交到代码仓库。助手日志和状态脚本不会打印它。

## 四、在 Chrome 中加载扩展并配对

1. 打开 Chrome，在地址栏进入 `chrome://extensions/`。
2. 打开右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本项目中的 `extension/` 文件夹。
5. 点击扩展卡片的“详细信息”→“扩展程序选项”，或者打开扩展弹窗后点击“设置”。
6. 将配对密钥粘贴到“配对密钥”，点击“保存密钥”，再点击“测试连接”。

密钥只保存在这台 Mac 的 Chrome 本地存储中，不同步到其他设备。

## 五、下载视频

1. 在 Chrome 打开你有权下载的视频页面。
2. 先播放视频几秒，让页面真正加载媒体请求。
3. 点击工具栏中的“网页视频港”图标。
4. 如果没有候选，点击“重新扫描”。
5. MP4 可以直接下载。M3U8 会先检查清单；如果有多个画质，选择需要的画质后点击“下载”。
6. YouTube 或哔哩哔哩的公开单个视频页面会显示平台卡片，可选最佳画质、1080P 或 720P。这里的 1080P/720P 是上限；源站没有对应清晰度时会选择不高于该上限的可用画质。音视频会由 FFmpeg 合并，最终根据源格式兼容性保存为 MP4 或 MKV。
7. 在“下载任务”中查看进度，可取消或重试。完成后点击 Finder 操作定位文件。

默认文件保存到 `~/Downloads/WebVideoHarbor/`。同名文件不会被覆盖，助手会生成安全的新文件名。

## 六、支持范围与限制

支持：

- 浏览器能够直接访问的普通 HTTP(S) MP4。
- 非加密、非 DRM 的 M3U8/HLS，包括单画质和多画质清单。
- 无需登录即可播放的 YouTube、YouTube Shorts 与哔哩哔哩公开单个视频页面。

明确不支持：

- DRM 或加密 HLS 分片。
- Blob-only 视频；如果页面只给出 `blob:` 地址，又没有可独立访问的普通 MP4/M3U8 请求，助手没有可下载的源地址。
- 必须携带 Cookie、Authorization 授权头或其他登录凭证才能访问的私有媒体流。
- YouTube 或哔哩哔哩播放列表，以及需要登录、会员、付费、私有权限、地区解锁或 DRM 的平台内容。
- 只能在专用客户端内部访问的内容，以及绕过登录、付费墙、地区限制或其他平台访问控制。

### 微信视频号

微信视频号属于最佳努力兼容，不承诺每条视频都能下载。请使用你有权访问的分享页，在 Chrome 中播放几秒后重新扫描。只有 Chrome 实际暴露为普通 MP4 或非加密 M3U8 的流才能进入正常流程；需要微信客户端内部凭证、Cookie、签名授权、加密或 DRM 的内容不支持。工具不会逆向凭证或规避限制。

## 七、从旧版升级到 v0.2.0

升级不会删除用户状态，建议按下面顺序操作：

1. 在旧安装目录运行 `./scripts/stop-helper.zsh`，先停止助手。
2. 下载并解压新版，然后用新版目录替换安装包；不要删除 `~/Library/Application Support/WebVideoHarbor/`。
3. 打开 `chrome://extensions/`，找到“网页视频港”并点击“重新加载扩展”；如果旧扩展目录已移动，重新选择新版 `extension/` 文件夹。
4. 在新版目录运行 `./scripts/start-helper.zsh`，重新启动助手。
5. 打开设置页测试连接。状态目录未被删除时会保留现有配对状态，不需要重新复制密钥。

## 八、隐私与本地安全

- 扩展不读取或导出 Cookie、Authorization 授权头、请求体、页面正文。
- 扩展只记录媒体候选所需的 URL 和安全响应元数据，不复制登录会话。
- 助手只监听回环地址 `127.0.0.1:17432`，不开放远程访问。
- 除公开的 `/health` 健康检查外，下载 API 必须携带随机 loopback token（配对密钥）。
- 配置和日志位于 `~/Library/Application Support/WebVideoHarbor/`；默认下载只写入 `~/Downloads/WebVideoHarbor/`。
- 日志不记录配对密钥、Cookie、授权头或请求体。
- 助手日志在运行期间自动限于 1 MiB；达到上限后保留近期诊断内容，不会持续占用磁盘。
- 日志按字节保留近期内容；极端情况下轮转后的首个 UTF-8 字符可能不完整，但不影响后续诊断信息。

## 九、故障排查

### 显示“未连接”

先运行状态脚本。如果助手未运行，重新启动；如果助手健康，重新复制配对密钥，在扩展 Options（设置）中保存并测试连接。不要在排查截图中露出密钥。

### FFmpeg 未安装

普通 MP4 仍可下载，但 M3U8 和平台音视频合并会被阻止。安装 FFmpeg 后停止并重新启动助手，再查看状态。

### 平台解析器缺失

如果状态页显示平台解析器不可用，确认正在完整安装包目录中运行，并检查 `work/dist/yt-dlp_macos` 是否存在且可执行。不要从不明来源补文件；重新下载并替换完整安装包，然后重启助手。

### 提示“平台解析规则已变化”

内置 yt-dlp 不会静默更新。出现该提示通常表示 YouTube 或哔哩哔哩已改变页面规则，请升级 WebVideoHarbor，或等待项目发布包含新版固定解析器的安装包。

### YouTube 提示 PO Token 或暂时无法解析

部分 YouTube 视频会要求 PO Token、登录或额外的站点验证。v0.2.0 不读取 Cookie，也不接入账号或 PO Token 提供器，因此这类视频可能无法下载。这属于上游访问限制，不代表普通 MP4、M3U8 或所有公开视频功能损坏。

### 无候选视频

确认视频已在当前 Chrome 标签页播放几秒，然后打开 popup（扩展弹窗）点击“重新扫描”。某些页面是 Blob-only，或媒体需要 Cookie/私有签名，这类情况不会产生可用候选。

### 提示加密或 DRM

这是受保护媒体，工具会主动停止，不提供解密或绕过功能。请使用内容平台提供的合法离线方式。

### 权限错误

确认当前用户对 `~/Downloads/WebVideoHarbor/` 和 `~/Library/Application Support/WebVideoHarbor/` 有所有权。不要把配置文件或目录改成符号链接，也不要开放给其他用户写入。

### 端口占用

助手固定使用 `127.0.0.1:17432`。先查看助手状态；如果状态显示未运行但端口仍被占用，请在“活动监视器”中确认占用者，不要随意结束身份不明的进程。启动脚本失败时会保留有界日志供检查。

## 十、停止助手

停止脚本只会向 PID 与预期助手命令均匹配的进程发送信号；身份不匹配时会拒绝操作：

```zsh
./scripts/stop-helper.zsh
```

停止助手不会删除配置、配对密钥或已经下载的视频。下次仍可直接启动。
