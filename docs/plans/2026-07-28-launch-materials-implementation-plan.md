# WebVideoHarbor Launch Materials Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Produce a complete first-week promotional starter pack for WebVideoHarbor Community Edition v1.0.0.

**Architecture:** The deliverable is a self-contained Markdown folder under the task's centralized `outputs/` link. Each file serves one publishing or support scenario, while all product claims are derived from the repository's README, installation guide, privacy statement, and usage boundaries.

**Tech Stack:** Markdown, existing GitHub Pages site, GitHub repository documentation.

---

### Task 1: Create the package structure and unified positioning

**Files:**
- Create: `outputs/WebVideoHarbor-第一周推广素材包/00-使用说明.md`
- Create: `outputs/WebVideoHarbor-第一周推广素材包/01-产品统一口径.md`

**Step 1:** Create the package index with recommended use order and canonical links.

**Step 2:** Write the one-line, short, medium, and long product descriptions.
