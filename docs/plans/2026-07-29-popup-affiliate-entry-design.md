# WebVideoHarbor 弹窗推荐入口设计

日期：2026-07-29  
状态：已确认

## 背景

当前联盟推荐入口只出现在扩展设置页底部、README 中段和官网首页下方。用户日常下载时主要使用扩展弹窗，不会频繁进入设置页或主动寻找推荐资源，因此入口曝光不足。

本次调整在不引入广告 SDK、遥测、点击统计和强制跳转的前提下，提高推荐入口在真实使用路径中的可见性。

## 目标

- 在扩展下载弹窗中提供始终可见、清晰标注“推广”的推荐入口。
- 下载任务在当前弹窗会话中完成时，增强一次入口的视觉和文案提示。
- 在官网顶部导航增加清晰可见的推荐页入口。
- 继续让扩展只链接项目自己的静态推荐页，不直接嵌入淘宝或阿里云推广地址。
- 不遮挡候选视频、下载按钮、任务状态和错误信息。

## 非目标

- 不添加弹窗广告、系统通知、自动打开网页或倒计时。
- 不要求用户点击推荐内容后才能使用下载功能。
- 不记录曝光、点击、下载记录、当前网页或媒体地址。
- 不引入第三方脚本、远程配置、动态广告位或个性化推荐。
- 不改变现有推荐商品和联盟链接。

## 方案比较

### 方案 A：只在弹窗底部常驻

实现简单、每次打开都有曝光，但容易形成横幅盲区，无法利用下载完成后的相关场景。

### 方案 B：只在下载完成后出现

提示时机与存储需求高度相关，但曝光次数有限；未完成任务或只打开弹窗查看的用户不会看到入口。

### 方案 C：常驻入口，完成后增强一次

弹窗底部始终显示紧凑入口；当前会话中有任务从未完成状态进入完成状态时，入口切换为强调状态。该方案兼顾稳定曝光、场景相关性和低打扰，确定采用。

## 弹窗交互

### 默认状态

推荐栏位于下载任务区域之后，并在弹窗滚动时保持在可见区域底部。它使用独立边框和浅色背景，但视觉权重低于下载按钮。

固定显示：

- 标识：`推广`
- 文案：`视频文件越来越多？查看存储与云服务推荐`
- 方向符号：`→`

整个推荐栏作为一个可聚焦链接，点击后在新标签页打开：

`https://phpfrank.github.io/web-video-harbor/recommendations.html`

### 下载完成强调状态

当弹窗打开期间，一个已观察到的任务从非完成状态进入完成状态时：

- 推荐栏增加强调样式，但不使用闪烁、抖动或循环动画。
- 文案切换为：`下载完成，需要更多存储空间？查看推荐`
- `推广`标识继续保留。
- 强调状态持续到当前弹窗关闭，不写入 Chrome 存储。

弹窗重新打开后恢复默认状态。历史完成任务不会反复触发强调。

### 异常与降级

- 推荐页无法访问时不影响扫描、下载、取消、重试和 Finder 定位。
- 入口使用普通外部链接，不依赖本地助手是否在线。
- JavaScript 状态更新失败时保留默认常驻入口，不隐藏核心功能。

## 状态与数据流

弹窗控制器只在内存中保存本次弹窗会话已经观察到的任务状态。首次任务刷新建立基线；后续刷新如果发现同一任务由非完成状态变为完成状态，则切换推荐栏的本地展示状态。

该状态不包含媒体地址、网页地址、文件名、配对密钥或联盟参数，也不写入 `chrome.storage`。点击入口时只发送固定的 GitHub Pages URL，不附加查询参数。

## 官网入口

官网首页顶部导航增加：`推荐资源·推广`，链接到 `recommendations.html`。原首页下方推荐模块继续保留，让桌面和移动端用户都能从顶部直接进入，也能在浏览产品说明后再次看到入口。

推荐详情页继续保留统一推广披露、两张带“推广”标识的卡片和数据边界说明。

## 视觉与可访问性

- 常驻栏高度保持紧凑，避免明显压缩候选和任务区域。
- 使用现有颜色变量、边框、圆角和焦点样式，不引入新的视觉体系。
- 链接保留明确的 `target="_blank"`、`rel="noopener noreferrer"` 和新窗口辅助文本。
- `推广`必须是可见文字，不能只通过颜色或图标表达。
- 窄屏下文案允许换行，点击区域保持至少 44 像素高。
- 键盘导航顺序为任务操作之后、页面脚本之前。

## 测试与验收

- HTML 合约测试：弹窗存在固定推荐页链接、可见推广标识，且不包含淘宝或阿里云地址。
- 控制器测试：首次任务刷新不触发；任务从等待、下载中或处理中变为完成时触发；历史完成任务和失败任务不触发。
- 会话测试：重新创建控制器后恢复默认状态，不使用持久化存储。
- 网站测试：顶部导航包含 `recommendations.html` 和可见推广披露。
- 隐私测试：扩展中不出现联盟目标地址、统计脚本或动态查询参数。
- 视觉检查：正常、空列表、多任务和窄屏场景下不遮挡核心按钮，不产生横向滚动。

## 效果判断

项目本身不增加统计。点击与转化效果继续通过淘宝和阿里云联盟后台观察；首轮至少运行一周，再根据实际点击决定是否调整文案或位置，不用频繁增加更多广告位。
