# WebVideoHarbor 非商业授权设计

## 背景

WebVideoHarbor 当前以 MIT License 发布。MIT 允许任何人保留版权与许可声明后复制、修改、闭源、分发和商业使用。项目维护者希望继续公开源码并允许个人学习、研究、修改和非商业分发，但不再授权第三方将未来版本用于商业目的。

仓库在换证前的最后一个提交是 `b56aa8c`。该提交及更早修订已经在 MIT License 下公开，既有授权不因后续换证而追溯失效。

Git 历史中的 `PHPfrank` 和 `lifeng` 提交身份已经由项目维护者确认为同一人。所有新增的对外版权、授权和品牌声明只使用 `PHPfrank`；历史作者信息保持不变。

## 目标

- 从换证提交开始，以标准化的非商业软件许可证发布 WebVideoHarbor。
- 允许个人学习、研究、测试、业余修改和非商业分发。
- 禁止未经书面许可的商业使用。
- 清楚披露历史 MIT 授权边界，避免制造可追溯撤销的误解。
- 保留 WebVideoHarbor、网页视频港及官方品牌标识的品牌权利。
- 保持所有第三方组件原有许可证和归属不变。

## 非目标

- 不尝试撤销 `b56aa8c` 及更早修订的 MIT 授权。
- 不修改或重新许可 Go、yt-dlp、Deno、FFmpeg、Chrome 或 Chromium。
- 不改写 Git 历史、作者姓名或作者邮箱。
- 不自行起草非标准软件许可证。
- 本次不发布新安装包，也不改变当前下载版本号。

## 方案比较

### 方案一：继续使用 MIT

兼容性和传播范围最大，但无法禁止闭源和商业使用，不满足核心目标。

### 方案二：保留全部权利或将仓库私有化

控制力最强，但不再允许社区合法修改和分发，也不符合继续公开源码的目标。

### 方案三：PolyForm Noncommercial 1.0.0

允许非商业使用、修改和分发，同时不授予商业用途。它是面向软件的标准化源码可用许可证，比自行修改 MIT 或使用 Creative Commons 许可证更清晰。该方案满足当前目标，因此采用。

## 授权设计

根目录 `LICENSE` 使用未经改写的 PolyForm Noncommercial License 1.0.0 正文。单独的 `NOTICE` 文件提供许可证所支持的 Required Notice，声明 PHPfrank 的版权和官方仓库地址。

README 将项目表述从“开源”调整为“源码公开”，并明确：

- 当前主分支以及未来版本采用 PolyForm Noncommercial 1.0.0；
- 个人学习、研究、测试、业余项目及其他许可证允许的非商业用途可以使用；
- 商业用途需要事先获得 PHPfrank 的书面许可；
- `b56aa8c` 及更早修订仍按当时的 MIT License 使用；
- 第三方组件继续按各自许可证使用。

`THIRD_PARTY_NOTICES.md` 只更新 WebVideoHarbor 自有代码的许可证描述，不改变任何第三方组件条款。

## 品牌设计

新增 `TRADEMARKS.md`：

- 源码许可证不授予 WebVideoHarbor、网页视频港、Logo 或其他官方品牌元素的商标权；
- 允许为说明兼容性、来源或贡献而进行准确的文字引用；
- 衍生版本必须更换名称和品牌标识，并清楚声明其并非官方版本；
- 未经书面许可，不得使用官方品牌发布应用、安装包、网站、账号或商业服务，也不得暗示官方背书。
