# macOS 网页视频下载器设计

## 目标

开发一套由 Chrome 扩展和 macOS 本地下载助手组成的网页视频下载工具。工具检测当前网页中的 MP4 与非 DRM M3U8 媒体，允许用户选择清晰度，并将内容保存为本地 MP4 文件。

第一版面向 macOS，提供微信视频号兼容模式。兼容模式仅处理能在 Chrome 中播放且暴露为普通 MP4 或非 DRM M3U8 的视频，不绕过登录、付费、DRM、加密分片或平台访问控制。

## 方案选择

### 纯 Chrome 扩展

安装简单，但长视频会占用大量浏览器内存，M3U8 合并、失败重试和后台任务的可靠性不足。

### 独立 macOS 应用

本地下载能力强，但难以直接获取当前网页加载的视频资源和浏览器上下文。

### Chrome 扩展加本地助手

扩展负责发现和呈现媒体，本地助手负责下载、重试、任务管理和 FFmpeg 合并。该方案兼顾网页检测能力、下载稳定性与简单操作，作为第一版实现路线。

## 系统架构

系统包含四个部分：

1. Chrome Manifest V3 扩展：扫描页面元素和媒体网络请求，去重后展示候选视频。
2. 扩展后台服务：保存当前标签页候选项，连接本地助手并轮询任务状态。
3. Go 本地助手：仅监听 `127.0.0.1`，校验配对密钥，检查下载目标并管理任务。
4. FFmpeg：下载或合并 HLS 媒体，在可行时以流复制方式生成 MP4，避免重新编码和画质损失。

扩展与助手通过本机 HTTP JSON API 通信。助手只接受本机请求，使用随机配对密钥，并对来源、方法、请求大小和 URL 目标进行限制。

## 媒体发现

扩展使用两类信息发现媒体：

- 页面扫描：读取 `video.currentSrc`、`video.src`、`source.src` 以及与媒体相关的页面资源记录。
- 请求观察：记录标签页加载的 MP4、M3U8 和常见 HLS 请求，并根据类型、扩展名和请求上下文过滤噪声。

候选资源按规范化 URL 去重。若视频需要播放后才加载，界面提示用户播放几秒后重新扫描。

微信视频号兼容模式复用相同机制，并加强对动态媒体请求的收集。只有浏览器实际加载的普通媒体资源才会进入候选列表。

## 用户流程与界面

1. 用户在 Chrome 中打开网页并播放视频几秒。
2. 用户打开扩展弹窗，查看助手连接状态和检测到的视频。
3. 对主 M3U8 播放列表，助手读取可用变体并返回分辨率与带宽信息。
4. 用户选择清晰度并提交下载。
5. 弹窗显示等待、下载、合并、完成或失败状态，并提供取消和重试。
6. 下载完成后，用户可打开文件或下载目录。

界面使用中文，采用原生 HTML、CSS 与 JavaScript。默认下载目录为 `~/Downloads/网页视频下载器/`，文件名会清理 macOS 不适合的字符并避免覆盖已有文件。

## 本地助手 API

第一版提供以下本机接口：

- `GET /health`：检查助手和 FFmpeg 状态。
- `POST /v1/inspect`：检查媒体类型并解析 M3U8 清晰度。
- `POST /v1/tasks`：创建下载任务。
- `GET /v1/tasks`：列出任务。
- `GET /v1/tasks/{id}`：查询任务状态与进度。
- `POST /v1/tasks/{id}/cancel`：取消任务。
- `POST /v1/tasks/{id}/retry`：重试失败任务。
- `POST /v1/tasks/{id}/reveal`：在 Finder 中显示完成的文件。

任务状态为 queued、downloading、merging、completed、failed 或 canceled。状态保存在内存中；第一版不承诺助手重启后恢复未完成任务。

## 下载行为

直接 MP4 由本地助手流式写入临时文件，成功后原子移动到最终位置。M3U8 交给 FFmpeg 处理，优先使用流复制输出 MP4。临时文件放在下载目录的隐藏临时子目录中，失败和取消后安全清理对应任务文件。

网络失败默认最多重试三次，并使用递增等待时间。已存在的文件不会被覆盖，助手自动添加序号。链接过期、服务器拒绝、FFmpeg 缺失和输出格式不兼容均返回可读的中文错误。

## 安全与隐私

- 助手仅绑定回环地址，不接受局域网或公网连接。
- API 使用随机密钥鉴权，并限制允许的扩展来源。
- 下载 URL 仅允许 HTTP 和 HTTPS。
- URL 校验拒绝回环、链路本地和私有网络目标，重定向后再次校验。
- 第一版不导出浏览器 Cookie，不自动复用敏感登录凭证。
- 日志不记录配对密钥、完整 Cookie 或其他认证信息。
- 工具不提供 DRM 绕过、付费内容破解或权限规避功能。

## 异常处理

- 助手未连接：显示安装或启动提示。
- FFmpeg 缺失：显示检测结果和安装指引。
- 页面未发现媒体：提示播放视频后重新扫描。
- 链接过期或服务器拒绝：标记任务失败并允许重试。
- 加密或 DRM 媒体：停止任务并说明不支持的原因。
- 需要微信客户端内部凭证：标记为当前版本不支持。

## 测试策略

### 单元测试

- URL 类型判断、规范化与去重。
- 文件名清理和防覆盖命名。
- 私有网络及回环目标拒绝。
- M3U8 主列表变体解析。
- 任务状态转换、取消与重试。

### 集成测试

- 本地测试服务器提供直接 MP4、单码率 M3U8 和多码率 M3U8。
- 验证助手健康检查、检查媒体、创建任务、查询进度和取消任务。
- 验证错误链接、服务器中断、FFmpeg 缺失和无效输出。

### 浏览器验证

- 验证 DOM 与请求观察两种媒体发现方式。
- 验证弹窗的视频列表、清晰度选择和任务状态。
- 完成一次从网页检测到生成 MP4 的端到端流程。
- 使用用户有权下载的视频号分享链接进行最佳努力兼容测试。

## 第一版交付物

- 可通过 Chrome“加载已解压的扩展程序”安装的扩展目录。
- 可在当前 Mac 上运行的本地助手二进制文件。
- 启动、停止和状态检查脚本。
- 中文安装与使用说明。
- 示例媒体页面、测试夹具和自动化测试。

## 非目标

- App Store 分发、Apple 签名和公证。
- 自动导出或复制浏览器登录 Cookie。
- 下载只能在微信客户端内部访问的视频。
- 绕过 DRM、加密、付费墙或其他平台保护。
- 保证所有微信视频号内容都能下载。
