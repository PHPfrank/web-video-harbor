# WebVideoHarbor 使用边界

WebVideoHarbor Community Edition 是用于学习网页媒体识别、非加密 HLS 处理和浏览器与本地程序通信的开源技术项目。请只处理你有权保存的内容。

## 默认能力

- 普通 HTTP(S) MP4 和 WebM。
- 非加密、非 DRM 的 M3U8/HLS，包括单画质和多画质清单。
- 下载进度、取消、重试及 Finder 定位。

## 实验性平台兼容

针对 YouTube、哔哩哔哩及微信视频号页面的兼容能力保留在开源代码和完整包中，但默认关闭。扩展和本地助手都会执行该开关。用户必须在设置页阅读说明并主动确认，才能在本机开启。

该模块仅尝试处理无需登录便可公开访问的单个视频，以及页面已向 Chrome 暴露的普通 MP4 或非加密 M3U8。平台规则、网络条件和内容权限可能导致任务失败。

## 明确不支持

- 需要 Cookie、Authorization、登录、用户账号或其他会话凭证的内容。
- 会员、付费、私有、年龄受限或只对特定用户开放的内容。
- 加密 HLS、DRM、密钥提取或受保护媒体解密。
- 规避地区限制、付费墙、访问控制、频率限制或机器人验证。
- 导出 Cookie、复用用户会话、注入令牌、模拟账号操作或绕过验证。
- 为非法复制、传播、侵犯著作权或违反网站规则的行为提供帮助。
