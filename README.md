# WebVideoHarbor（网页视频港）

WebVideoHarbor 是一个由 Chrome 扩展和 macOS 本地助手组成、重视隐私与安全边界的网页视频保存工具。扩展可以发现当前页面中浏览器实际暴露的 MP4 或 M3U8 地址；v0.2.0 还支持 YouTube 与哔哩哔哩无需登录即可观看的公开单个视频页面。本地助手负责下载、检查和合并，M3U8 与平台音视频合并依赖 FFmpeg。

## 能做什么

- 下载普通 HTTP(S) MP4。
- 下载并合并非加密、非 DRM 的 M3U8/HLS；多画质清单可选择清晰度。
- 下载公开的 YouTube、YouTube Shorts 和哔哩哔哩单个视频；可选最佳画质、1080P 或 720P，最终文件根据源格式兼容性保存为 MP4 或 MKV。
- 对微信视频号做最佳努力兼容：仅当 Chrome 在播放过程中暴露普通 MP4 或非加密 M3U8 时才可能识别。
- 在弹窗中查看进度、取消、重试，并在完成后通过 Finder 定位文件。

平台下载仅支持一个公开视频，不支持播放列表，也不支持需要 Cookie、登录、会员、付费、地区解锁或 DRM 的内容。工具不会绕过访问控制或导出 Cookie。Blob-only、只能携带登录凭证访问的私有媒体流也可能无法下载。请只下载自己有权保存的内容。

macOS 安装包固定内置 `yt-dlp 2026.07.04`，不会静默更新；平台解析规则变化时需要升级 WebVideoHarbor。

## 快速开始

详细步骤、Chrome 安装方式和故障排查见 [安装使用说明](docs/安装使用说明.md)。从项目根目录开始：

1. 安装构建工具与 FFmpeg。
2. 构建并启动本地助手。
3. 在 Chrome 中“加载已解压的扩展程序”，选择本项目的 `extension/` 文件夹。
4. 获取配对密钥，在扩展的“设置”页面保存并测试连接。
5. 播放目标视频几秒，打开扩展弹窗并重新扫描。

默认下载目录是 `~/Downloads/WebVideoHarbor/`。本地状态只保存在 `~/Library/Application Support/WebVideoHarbor/`。

## 安全边界

本地助手仅监听 `127.0.0.1:17432`，受随机配对密钥保护。扩展不读取或导出 Cookie、授权头、请求体或页面正文；FFmpeg 也不会直接接触远程 URL。配对密钥相当于本机控制凭证，请勿分享或截图传播。

## 从 v0.1.0 升级

依次停止助手、替换安装包、在 Chrome 中重新加载扩展，再启动助手。`~/Library/Application Support/WebVideoHarbor/` 不随安装包替换，因此会保留现有配对状态和下载目录设置。完整操作见安装使用说明。
